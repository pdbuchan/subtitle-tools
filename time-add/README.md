# time-add

Adds two timestamps entered through standard input and prints the sum as a timestamp.

## Build

```sh
gcc -Wall time-add.c -o time-add
```

## Usage

```sh
./time-add
```

The program prompts for a starting timestamp and an additional time. Results are written to standard output.
