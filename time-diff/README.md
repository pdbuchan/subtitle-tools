# time-diff

Calculates the difference between two timestamps entered through standard input and prints the result as a timestamp.

## Build

```sh
gcc -Wall time-diff.c -o time-diff
```

## Usage

```sh
./time-diff
```

The program prompts for a starting and ending timestamp. Results are written to standard output.
